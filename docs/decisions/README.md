# Architecture decision records

Significant architectural decisions for the Tensura Quests ecosystem, one file
per decision. Each ADR carries context, the problem, the options considered,
the decision, rationale, consequences, status and date.

An accepted ADR is not changed silently. If research invalidates one, write a
replacement ADR that supersedes it and explain the impact; keep the old file
for history.
